# 🔤 Hiragana (ひらがな) — La Voz Nativa y Sistema de Etiquetas

**Pertenencia:** [[000_MAPA_RUTA_JAPONES]]  
**Tags:** #japonés/escritura #hiragana #nivel/N5  

---

## 💡 Concepto
El Hiragana es el silabario principal del japonés. Se utiliza para escribir palabras de origen nativo, sufijos gramaticales y **partículas** (los conectores de la frase).

* **Regla de oro:** Es un sistema fonético puro de **46 caracteres básicos**. Cada letra suena **siempre exactamente igual**, a diferencia del español o el inglés donde las vocales cambian según la palabra.

---

## 1. Los 46 Caracteres Básicos (Gojūon / 五十音)

```text
Vocales:      あ (a)    い (i)    う (u)    え (e)    お (o)
Familia K:    か (ka)   き (ki)   く (ku)   け (ke)   こ (ko)
Familia S:    さ (sa)   し (shi)  す (su)   せ (se)   そ (so)
Familia T:    た (ta)   ち (chi)  つ (tsu)  て (te)   と (to)
Familia N:    な (na)   に (ni)   ぬ (nu)   ね (ne)   の (no)
Familia H:    は (ha)   ひ (hi)   ふ (fu)   へ (he)   ほ (ho)
Familia M:    ま (ma)   み (mi)   む (mu)   め (me)   も (mo)
Familia Y:    や (ya)             ゆ (yu)             よ (yo)
Familia R:    ら (ra)   り (ri)   る (ru)   れ (re)   ろ (ro)
Familia W/N:  わ (wa)                       を (o/wo) ん (n)
````
2. Las Variaciones de Sonido (Dakuten y Handakuten)
Al añadir dos rayitas (dakuten ゛) o un circulito (handakuten ゜) a la esquina superior derecha, transformas el sonido sin necesidad de aprender un trazo nuevo.

🔹 Con comillas ( ゛) — Sonidos Sonoros
Familia G (de la K): が (ga), ぎ (gi), ぐ (gu), げ (ge), ご (go)

Familia Z (de la S): ざ (za), じ (ji), ず (zu), ぜ (ze), ぞ (zo)

Familia D (de la T): だ (da), ぢ (ji), づ (zu), で (de), ど (do)

Familia B (de la H): ば (ba), び (bi), ぶ (bu), べ (be), ぼ (bo)

🔹 Con circulito ( ゜) — Sonido P
Familia P (de la H): ぱ (pa), ぴ (pi), ぷ (pu), ぺ (pe), ぽ (po)

3. Sonidos Combinados (Yōon / 拗音)
Se forman juntando una consonante acabada en vocal I (き, し, に, ひ, み, り, ぎ, じ, び, ぴ) + un carácter pequeñito de や (ya), ゆ (yu), よ (yo):

````text
きゃ (kya) / きゅ (kyu) / きょ (kyo)
しゃ (sha) / しゅ (shu) / しょ (sho)
ちゃ (cha) / ちゅ (chu) / ちょ (cho)
にゃ (nya) / にゅ (nyu) / にょ (nyo)
ひゃ (hya) / ひゅ (hyu) / ひょ (hyo)
みゃ (mya) / みゅ (myu) / みょ (myo)
りゃ (rya) / りゅ (ryu) / りょ (ryo)
ぎゃ (gya) / ぎゅ (gyu) / ぎょ (gyo)
じゃ (ja)  / じゅ (ju)  / じょ (jo)
びゃ (bya) / びゅ (byu) / びょ (byo)
ぴゃ (pya) / ぴゅ (pyu) / ぴょ (pyo)
````

🏷️ MÓDULO 2: El Sistema de Etiquetas (Sufijos Instantáneos)
Cómo multiplicar tu vocabulario al instante combinando Katakana (País) + Sufijos de Hiragana/Kanji:

País + ~jin (人): Nacionalidad

Ejemplo: スペイン人 (Supeinjin) — Español/a.

Ejemplo: 日本人 (Nihonjin) — Japonés/a.

País + ~go (語): Idioma

Ejemplo: スペイン語 (Supeingo) — Idioma español.

Ejemplo: 日本語 (Nihongo) — Idioma japonés.

(Excepción: 英語 / Eigo — Inglés).

País + ~ryōri (料理): Gastronomía

Ejemplo: スペイン料理 (Supein-ryōri) — Comida española.

Ejemplo: 日本料理 (Nihon-ryōri) — Comida japonesa.

⚠️ Excepciones Fonéticas Cruciales para Partículas
Hay 3 caracteres Hiragana que cambian su pronunciación cuando funcionan como partículas gramaticales:

は (ha): Se pronuncia WA cuando marca el tema ([[Pilar_01_Sujeto_Identidad]]).

を (wo): Se pronuncia O cuando marca el objeto directo ([[Pilar_02_Objeto_Directo]]).

へ (he): Se pronuncia E cuando indica dirección o rumbo.
